# Kasauti — Deferred Features

> Items intentionally out of scope for the hackathon. Revisit post-buildathon.

## Authentication & Authorization
- User login / signup (OAuth, magic link, etc.)
- Role-based access control
- API key management for external consumers

## Billing & Multi-Tenancy
- Per-tenant data isolation
- Usage metering and invoicing
- Subscription tiers

## CI/CD Integrations
- GitHub Actions / GitLab CI pipeline triggers
- Slack / Teams notifications on run completion
- Webhook-based integrations with third-party tools

## Noise & Network Simulation
- Simulated poor network quality (jitter, packet loss)
- Background noise injection (traffic, crowd, etc.)
- Codec degradation testing

## Non-Bolna Agent Adapters
- Bland.ai adapter
- Retell adapter
- Vapi adapter
- Generic SIP adapter

## Advanced Scenario Features
- Dynamic persona generation via LLM
- Scenario chaining (multi-call flows)
- A/B testing across prompt variants
- Statistical significance calculation for pass-rate changes

## Reporting Enhancements
- Historical trend graphs
- Regression detection across runs
- Email delivery of PDF reports
- Scheduled recurring test runs

## Audio Analysis
- Latency measurement (time-to-first-byte of agent response)
- Silence detection and quantification
- Interruption overlap analysis
- Speech-to-text accuracy comparison

## TRAI Compliance Depth
- Full TRAI regulation text integration (pending legal review)
- DND registry lookup integration
- Automated consent flow verification
- Call recording retention policy checks
